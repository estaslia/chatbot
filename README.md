## Overview

The Cyber Security Chatbot is a console based application developed in C#. It is designed to educate users about basic cybersecurity concepts while providing an interactive chat experience. The chatbot allows users to learn about topics such as phishing, passwords, malware, and firewalls in a simple and user-friendly way.

---

## Features

* Interactive chatbot conversation
* User-friendly menu system
* Personalized user experience (name input)
* Cybersecurity topic explanations:

  * Phishing
  * Password Safety
  * Malware
  * Firewalls
* Continuous chat mode with exit option
* ASCII art welcome screen

---

## Technologies Used

* C# (.NET Console Application)
* Object-Oriented Programming (OOP)

---

##  Project Structure

The project is divided into multiple classes for better organization:

* **Chatbot.cs**
  Controls the main program flow and user interaction.

* **UIHelper.cs**
  Handles display elements such as menus, text formatting, and user prompts.

* **ChatHandler.cs**
  Manages chatbot responses based on user input.

* **TopicHandler.cs**
  Contains cybersecurity educational content.

---

##  How It Works

1. The program starts by displaying ASCII art.
2. A greeting message is shown.
3. The user enters their name.
4. A menu is displayed with multiple options.
5. The user selects:

   * Chat mode
   * Cybersecurity topics
   * Exit program
6. The system responds accordingly and returns to the menu unless exited.

---

## How to Run the Program

1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
4. Follow the on-screen instructions.

---

## Example Usage

* Enter your name when prompted.
* Choose option `1` to chat with the bot.
* Type `menu` anytime in chat mode to return to the main menu.
* Select topics to learn about cybersecurity concepts.
